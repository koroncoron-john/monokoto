# ものコトMarket 仕様書

地域の「モノ（商品）」「コト（体験・イベント）」「ノート（地域情報）」を扱う、マルチマーケット型のマーケットプレイスです。

このリポジトリは、Bubbleアプリ `monokoto-market` の **Testブランチ**を基準に、現行仕様を人が読める形で整理したものです。GitHubの対象ブランチは `main` です。

## 文書の読み方

- **現行仕様**: BubbleのTestブランチから確認できた挙動・設定です。
- **要確認**: 実装上のリスク、意図を担当者に確認すべき点です。
- データベース内の実データ、外部サービス側の設定、Bubbleで公開済みのLiveブランチとの差分は対象外です。
- 認証情報、秘密鍵、個人情報、テスト用アカウント値は記載していません。

## 更新ルール

Bubbleの仕様変更と同じPull Requestで該当文書を更新してください。少なくとも、画面追加、フィールド変更、ステータス追加、決済・通知処理変更、Privacy Rules変更は文書更新の対象です。
